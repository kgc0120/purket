자주 묻는 질문

계정 없이 사용할 수 있나요?

네. 로그인하지 않아도 모든 기본 가계부 기능을 사용할 수 있으며, 이 경우 데이터는 기기 내에만 저장됩니다. 앱을 삭제하면 데이터도 함께 삭제되니 주의해 주세요.

회원가입/로그인은 무엇을 위한 기능인가요?

이메일 계정으로 로그인하면 클라우드 백업, 기기 변경 시 데이터 복원, 다른 사람과의 포켓 공유 기능을 이용할 수 있습니다. 로그인 후에는 가계부 데이터가 안전한 클라우드 서버에 저장됩니다.

내 데이터는 어디에 저장되나요?

미로그인 상태에서는 기기 내에만 저장됩니다. 로그인한 경우에는 데이터가 기기에 저장되면서 동시에 대한민국(서울) 리전의 클라우드 서버에도 저장·동기화됩니다. 서버와의 통신은 HTTPS로 암호화되며, 본인과 공유를 승인한 사용자만 데이터에 접근할 수 있습니다.

포켓 공유는 어떻게 동작하나요?

로그인한 사용자는 특정 포켓을 다른 사용자와 공유할 수 있습니다. 초대 링크를 생성하여 상대방에게 전달하고, 상대방이 링크를 눌러 수락하면 해당 포켓의 내역을 함께 조회/기록할 수 있습니다. 공유 시 상대방에게는 소유자의 닉네임이 표시됩니다.

계정을 삭제하고 싶어요.

계정 삭제를 원하시면 위 이메일로 요청해 주세요. 계정과 그에 연결된 모든 가계부·공유 데이터가 서버에서 삭제됩니다.

백업/복원은 지원하나요?

로그인한 계정 기준으로 서버 백업 및 복원이 자동으로 이루어집니다. 미로그인 상태에서는 iOS의 iCloud 기기 백업에 포함될 수 있으나 개발자가 접근할 수는 없습니다.

로그인이 안 되거나 동기화가 안 돼요.

네트워크 연결 상태와 앱/OS가 최신 버전인지 먼저 확인해 주세요. 오프라인 상태에서 입력한 변경 사항은 온라인 복귀 시 자동으로 서버와 동기화됩니다.

문제 해결 체크리스트

  1. 앱/OS 최신 버전인지 확인
  2. 네트워크(Wi-Fi/셀룰러) 연결 상태 확인
  3. 저장 공간이 충분한지 확인
  4. 앱 재시작 및 기기 재부팅
  5. 계정 관련 오류라면 로그아웃 후 재로그인
